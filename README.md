# Mój Portfel — wydania

Gotowe pliki aplikacji Mój Portfel (Windows, Android, przeglądarka) w zakładce **Releases**. Zainstalowane aplikacje
same sprawdzają tu aktualizacje. Kod źródłowy jest w prywatnym repozytorium.

- Windows: instalator MojPortfel-Setup-*.exe (program przed instalacją aktualizacji sprawdza jej podpis).
- Android: plik .apk (telefon instaluje aktualizację tylko z tym samym podpisem co zainstalowana aplikacja).
- Przeglądarka: plik .html.
- Sumy kontrolne SHA-256: SHA256SUMS.txt w każdym wydaniu.
